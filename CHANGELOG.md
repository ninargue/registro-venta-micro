# Changelog

Todos los cambios relevantes de **registro-venta-micro** se documentan en este archivo.

El formato se basa en [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y el proyecto usa [Versionado Semántico](https://semver.org/lang/es/).

Este archivo no se edita en cada PR: se genera en cada release o hotfix a partir de las etiquetas de los PRs. Ver [Changelog en CONTRIBUTING.md](.github/CONTRIBUTING.md#changelog).

Secciones posibles por versión (según `.github/release.yml`):

- ⚠️ Cambios incompatibles
- 🔒 Seguridad
- 🗄️ Migraciones de base de datos
- ✨ Nuevas funcionalidades
- 🐛 Correcciones
- ♻️ Refactor
- 📝 Documentación
- 🧰 Mantenimiento y pruebas
- Otros cambios
